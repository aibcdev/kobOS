# getkob.com

Product site for the Alven-style employee build (Talk-first).

## Ship rule

- Push `aibcdev/kobOS` `main` via Git only.
- Never `netlify deploy --prod` to trykob.com / site kobkob.

## Domain

Attach **getkob.com** in Netlify UI as a domain (or alias) on the kobOS site after this product lands on `main`.

trykob.com may keep serving the same Git deploy until DNS points getkob.com at it.
